Usage: glh [--profile] <name> [options] [app-args...]
       glh plugin --profile <name> <pnpm-args...>

glh: boot a GLKJ Harness profile — an ordered stack of plugin-bundle patch
layers under your own overrides.

Arguments:
  args                           arguments for the booted profile's app (see:
                                 glh --profile <name> --help)

Options:
  -V, --version                  output the version number
  --profile <name>               the profile under $GLH_HOME/profiles to boot
  --from-default-profile <name>  replace a custom profile with a fresh copy of a
                                 shipped profile template
  --patch <path>                 extra patch-list overlay applied after the
                                 profile layer (repeatable)
  --dump-config                  print the composed profile tree and exit
  --dump-config-schema           print JSON Schema for profile entries and
                                 patches without mounting
  --dump-default-config          print the profile tree without its user layer
                                 or --patch overlays and exit

Examples:
  glh web                                   boot the web profile (same as: glh --profile web)
  glh rescue --from-default-profile web
                                            recreate rescue from the shipped web template, then boot it
  glh headless "run the tests"              answer one task, print the result, and exit
  glh tui --patch ./extra.yml               boot a custom profile with one extra overlay
  glh tui --resume <session>                arguments after the launcher flags reach the app
  glh web --help                            the web app's own flags and help
  glh plugin --profile tui add <package>    install a plugin into the tui profile
